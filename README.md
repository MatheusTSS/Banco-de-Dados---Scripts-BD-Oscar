

<h2>Descrição</h2>
<p>O <strong>Banco de Dados - Scripts BD Oscar</strong> é um projeto voltado para o estudo e manipulação de bancos de dados com foco na base de dados do Oscar. O projeto permite criar, popular e consultar informações sobre filmes, diretores, categorias e vencedores da premiação.</p>

<h2>Funcionalidades</h2>
<ul>
    <li><strong>Criação de Estrutura Relacional</strong>: Scripts para criação de tabelas com chaves primárias e estrangeiras.</li>
    <li><strong>Inserção de Dados</strong>: Scripts SQL para inserção de dados reais dos vencedores do Oscar.</li>
    <li><strong>Consultas SQL</strong>: Queries que permitem buscar informações como filmes vencedores por ano, diretores mais premiados, etc.</li>
    <li><strong>Relacionamento de Tabelas</strong>: Exploração de relações entre filmes, categorias e artistas premiados.</li>
    <li><strong>Desempenho de Consultas</strong>: Uso de índices e boas práticas para performance de leitura.</li>
</ul>

<h2>Tecnologias Utilizadas</h2>
<ul>
    <li><strong>SQL</strong>: Linguagem de manipulação e consulta de dados.</li>
    <li><strong>MySQL / PostgreSQL / SQL Server</strong>: Banco de dados relacional utilizado (dependendo do ambiente).</li>
    <li><strong>Workbench / DBeaver / PgAdmin</strong>: Ferramentas de gerenciamento e execução dos scripts SQL.</li>
</ul>
